## 🚀 Getting Started
### Installation
1. Clone the repo:
   ```bash
   git clone https://github.com/TusharJiShukla/webathon.git
   cd webathon
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development environment:
   ```bash
   npm start
   ```
